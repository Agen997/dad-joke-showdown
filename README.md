Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun: one dad joke, at most 200 characters, judged pairwise by a judge model on the pun, the groan, and the straight-faced delivery.

`main.ts` (Node 22, stdlib only) scores a shortlist of six original dad jokes against the judge's five criteria — in the brief's own order — and writes the winner to `/output/entry.txt`.

The winner:

> I told the lawn I'd mow it. It said, 'Cut it out — I'm already short.'

Double turn: "cut it out" (stop that / mow it) + "short" (grass height). 70 characters, one line, byte-identical across runs.
